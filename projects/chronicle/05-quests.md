# 任务系统｜用户明确描述的例子（重点保留）
用户希望所有加减乘除等都成为有故事动机的任务，不是单独题目。
## 采购→赚钱→跨地区运输→限时挑战
1. 引导：玩家手里有一定的钱，NPC带领认识价格、货币和购买，先买1件物品，理解一次交易。
2. 进阶：NPC需要3件同类物品，玩家钱不足，须先通过工作/贸易/运输等赚取资金，再购买3件，涉及加减、乘法、找零与预算。
3. 剧情：将货物交给指定人物，可能需要跨地方、跨国家；沿途接触语言与文化。
4. 航行：旅行需要1天、12小时、18小时等，NPC先讲时间概念，再要求算出发/到达时刻、是否赶得上某个时间节点。
5. 挑战：脱离详细引导，玩家在固定时间窗口内赚到目标金额、采购、安排航行并按时交付；可有策略空间，判定由规则引擎负责。
6. 任务成功给予游戏内奖励，可暂名“文明星核 Civilization Cores”，用于知识记录/未来基地修复；名称和经济平衡未确定。
## 长度、面积、周长的剧情化
港口码头/桥梁/庭院修复：先NPC指导测量木板或路线长度，选合适材料；后规划货物摆放区域、计算地面面积/围栏周长、材料数量与预算；再独立完成限定资源的工程挑战。数学知识与真实场景互动绑定，不凭空弹出公式题。
