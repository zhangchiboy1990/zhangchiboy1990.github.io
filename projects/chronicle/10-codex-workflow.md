# GitHub 与 Codex 工作流
GitHub作为项目资料的唯一权威版本。当前项目位于公开仓库 zhangchiboy1990/zhangchiboy1990.github.io 的 projects/chronicle/ 子目录；用户同意早期公开，后期需迁移到独立仓库或改为私有；迁移前不要提交机密、密钥或不希望公开的原创资产。当前未创建独立仓库，未连接/启动任何Codex任务。
Codex需要用户在Codex中连接GitHub并选择正确仓库/分支，才能读取这里的文件。GitHub更新不代表Codex会自动开始任务或实时同步到正在运行的会话；新任务/刷新工作区通常可获得最新提交，具体依赖Codex环境与拉取方式。后续在项目根放 AGENTS.md 说明开发约定，但现有仓库为个人网站，避免误影响无关代码；可放在 projects/chronicle/AGENTS.md。
每次变更：更新对应模块文档，记录版本和日期，区分已确认与待定；由Codex基于最新Git提交开发。长期可迁移为独立私有仓库。
